# Elevator Simulator (Java Swing)

A desktop application that simulates elevator movement with a graphical user interface.  
The project was created to practice object-oriented programming, GUI development and application logic in Java.



## 🚀 Features
```
- 🛗 Elevator movement simulation
- 🖥️ Graphical user interface built with Java Swing
- 🧍 Passenger and floor logic
- 🔼 Floor call buttons
- 🎯 Destination selection inside the cabin
- ⏱️ Animated movement using timers
- 🧱 Object-oriented project structure

```

## 📁 Project Structure

```
Elevator/
│
├── Cabin.java                 # elevator cabin model
├── Direction.java             # movement direction enum
├── ElevatorApp.java           # application entry point
├── ElevatorController.java    # main simulation logic
├── ElevatorGUI.java           # main GUI window
├── ElevatorView.java          # drawing and animation panel
├── Floor.java                 # floor model
└── Passenger.java             # passenger model

```
